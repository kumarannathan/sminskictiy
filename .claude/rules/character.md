# Smiski Character Design Rules

## Core Concept

The Smiski is a small, soft, physical creature.

It must feel:

- cute
- slightly mysterious
- expressive
- tactile
- physical
- lightweight
- playful

The body should remain visually simple.

---

# Rig

The Smiski should use a Roblox-compatible R15-based articulated rig.

The project should support standard R15 mapping while allowing additional
joints for improved articulation.

Roblox standard R15 provides 15 required poseable joints, while advanced
R15 supports additional joints for spine, clavicles, fingers, and toes.

Do not create a visually custom rig that cannot map to Roblox's character
animation systems.

---

# Body

The body should be:

- rounded
- soft
- minimal
- readable

Avoid excessive anatomical detail.

The character should remain recognizable at small screen sizes.

---

# Deformation

Skinning must support:

- walking
- running
- jumping
- sitting
- climbing
- reaching
- leaning
- carrying
- falling
- ragdoll
- getting up

Elbows and knees should bend naturally.

Avoid rigid "robotic" deformation.

---

# Face

The face is intentionally minimal.

Keep facial features:

- small
- simple
- readable

Expressions should be achieved through subtle changes rather than
large cartoon facial deformation.

---

# Backpack / Accessories

Accessories must not interfere with:

- shoulders
- arms
- head
- spine
- climbing
- sitting
- ragdoll

Accessories should be independently replaceable.

---

# Interaction

The character should support IK targets for:

- LeftHand
- RightHand
- LeftFoot
- RightFoot
- Head
- Chest
- Pelvis

The character should be designed around physical environmental interaction.
